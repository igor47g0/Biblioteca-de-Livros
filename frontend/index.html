🚀 Como Iniciar o Back-end Spring Boot

O erro ERR_CONNECTION_REFUSED acontece simplesmente quando o servidor Java não está rodando no computador na porta 8080.

Opção 1: Pelo IntelliJ IDEA (Recomendado)

  1. Abra o IntelliJ IDEA.
  2. Abra a pasta C:\Users\igor65974086\.gemini\antigravity\scratch\bibliotech\backend.
  3. Navegue até o arquivo src/main/java/com/bibliotech/BibliotechApplication.java.
  4. Clique no botão verde ▶️ Run 'BibliotechApplication' ao lado da classe.

Opção 2: Pelo Arquivo .bat Automático

  1. Vá até a pasta bibliotech/.
  2. Dê dois cliques no arquivo iniciar_backend.bat.

Opção 3: Modo Simulado (Já Disponível Aqui!)

Se você quiser testar as telas, tirar os prints das evidências (201, 200, 204, 400, 404, 409) agora mesmo sem precisar subir o MySQL, você pode usar o Modo Simulado clicando no botão no topo da página!
